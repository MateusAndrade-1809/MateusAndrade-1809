# Imagens e fontes

## Cenário do portfólio

`public/assets/forest-world.webp` foi gerado para este portfólio com a ferramenta de geração de imagens da OpenAI e convertido para WebP sem perda. Não é uma imagem de projeto do aluno nem uma fotografia do evento.

Direção utilizada: floresta medieval vista de cima, pixel art fina de 16 bits, mesma grade visual, árvores grandes e volumosas nas bordas, trilhas contínuas de terra, seis bases vazias para portais, clareira central, pedras pequenas, flores, rio e cachoeira à direita; sem interface, personagens, texto ou castelo. Os portais e o personagem são elementos interativos separados.

O avatar é a imagem pública do perfil GitHub `MateusAndrade-1809`. Não foram incluídas fotos de eventos que o aluno não forneceu.

## Bibliotecas visuais

- Ícones: Lucide, conforme licença distribuída com `lucide-react`.
- Fontes locais: Manrope, Cinzel e Pixelify Sans, distribuídas pelos pacotes Fontsource e suas licenças OFL.
- Dados meteorológicos: [Open-Meteo](https://open-meteo.com/), com atribuição no link de clima do mapa.
- Identidade, textos e imagens de projetos em equipe mantêm os créditos dos respectivos autores. A publicação do portfólio não altera as licenças desses projetos.
